# Raspberry grove backdrop

`raspberry_grove_cc0.jpg` is used only as a distant, non-interactive foliage
backdrop behind the simulated geometry.

- Source: [Rubus idaeus Oulu, Finland 09.06.2013](https://commons.wikimedia.org/wiki/File:Rubus_idaeus_Oulu,_Finland_09.06.2013.jpg)
- Photographer: Matti Virtala

The interactive raspberry, pedicle, branches, leaves, gripper and robot remain
rendered simulation geometry.
